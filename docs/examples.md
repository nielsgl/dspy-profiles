# Examples

This section highlights usage examples included in the repository. Run them with `dspy-run` to activate profiles from the command line.

- hello_world.py: Basic `profile()` context with a simple predictor
- hello_decorator.py: Applying `@with_profile` to a function
- decorator_usage.py: Decorator-focused example and narrative
- multiple_profiles.py: Switching profiles and printing the active one
- extended_profiles.py: Profile inheritance using `extends`
- profile_overrides.py: Overriding profile settings at runtime
- adaptive_agent.py: Advanced agent pattern with class decorator and conditional escalation
- hello_runner.py: Using `dspy-run` with a script, no code changes needed
- retrieval_example.py: Configuring and using a retrieval model via `rm.class_name`

For full details, open the files under the `examples/` directory.
